# بطاقات تهنئة بالمناسبات

مجموعة صفحات تهنئة إلكترونية، كل واحدة بتصميم وثيمة مختلفة تمامًا، من المقدم صابر إلى ضباط مختلفين. الموقع مستضاف على Vercel وبيتحدّث تلقائيًا مع كل push على هذا البرانش.

الدومين: `https://qrcode-three-blue.vercel.app`

| المناسبة | الصفحة | الرابط | QR |
|---|---|---|---|
| المولد النبوي الشريف | `index.html` | `/` | `qr/qr-mawlid.png` |
| عيد الفطر المبارك | `eid-fitr/index.html` | `/eid-fitr/` | `qr/qr-eid-fitr.png` |
| عيد الأضحى المبارك | `eid-adha/index.html` | `/eid-adha/` | `qr/qr-eid-adha.png` |
| رأس السنة الهجرية | `hijri-new-year/index.html` | `/hijri-new-year/` | `qr/qr-hijri-new-year.png` |
| عيد الشرطة المصرية | `police-day/index.html` | `/police-day/` | `qr/qr-police-day.png` |

كل صفحة مستقلة تمامًا (HTML/CSS/JS خام، بدون أي أدوات بناء)، وكل واحدة ليها QR خاص بيها جوه مجلد `qr/` جاهز للطباعة (دقة عالية، تصحيح أخطاء H).

لإضافة مناسبة جديدة: أنشئ مجلد جديد فيه `index.html` بنفس نمط الملفات الموجودة، وهيتاخد رابط تلقائي `/اسم-المجلد/` على نفس الدومين بمجرد الـ push.
