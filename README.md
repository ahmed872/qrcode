# تهنئة المولد النبوي الشريف

صفحة تهنئة إلكترونية بمناسبة المولد النبوي الشريف، من المقدم صابر إلى اللواء أحمد صابر.

- `index.html` — صفحة الويب (تُفتح مباشرة في المتصفح، أو تُفعَّل عليها GitHub Pages).
- `mawlid-qr.png` — كود QR جاهز للطباعة، يوجّه لصفحة الويب المستضافة (حاليًا نسخة Artifact على claude.ai).

لو حبيت تشغّل الصفحة من نفس الريبو عبر GitHub Pages، فعّلها من إعدادات الريبو (Settings → Pages) على البرانش الحالي، وبعدها أعِد توليد QR كود جديد بلينك صفحة الـ Pages بدل لينك الـ Artifact.
